# Инструкция по проверке оплаты

## Что изменилось

### ✅ Успешная оплата
1. После успешной оплаты пользователь попадает на **`/payment-check.html`**
2. Страница автоматически проверяет реальный статус через API
3. Если успех → редирект на **главную** с модальным окном успеха
4. Показывает сумму оплаты (если передана)

### ❌ Неудачная оплата / Отмена
1. При отмене/ошибке платежа ЮKassa возвращает на **`/payment-check.html`**
2. Страница проверяет статус и видит **не "succeeded"**
3. Автоматический редирект на **`/payment-failed.html`**
4. Страница показывает:
   - Иконку ошибки
   - Объяснение, что платёж не прошёл
   - Детали платежа (ID, статус, сумма)
   - Кнопки: "Попробовать снова" и "Вернуться на главную"
   - Ссылку на Telegram для поддержки

## Как это работает

### Поток оплаты:

```
Пользователь нажимает "Оплатить"
         ↓
POST /api/create-payment
         ↓
ЮKassa (страница оплаты)
         ↓
    [Пользователь оплачивает или отменяет]
         ↓
Возврат на /payment-check.html?payment_id=...
         ↓
    [Проверка статуса через API]
         ↓
    ┌──────┴──────┐
    ↓             ↓
Успех         Ошибка
    ↓             ↓
/?payment_    /payment-
success=true  failed.html
    ↓             ↓
Модальное     Страница
окно          ошибки
```

### Backend (`server.js`):
- `POST /api/create-payment` — создаёт платёж
  - return_url: `/payment-check.html?payment_id=...`
- `GET /api/payment/:id` — возвращает реальный статус платежа
  - Автоматически проверяет через ЮKassa API (если pending)
  - Обновляет статус в БД
- `GET /payment-failed` — редирект на страницу ошибки

### Frontend:
- **`payment-check.html`** — промежуточная страница проверки
  - Проверяет статус платежа через API
  - Автоматически редиректит на нужную страницу
  - Повторяет проверку до 10 раз (каждые 2 сек)
  
- **`index.html`** — главная страница
  - Проверяет `?payment_success=true` при загрузке
  - Показывает модальное окно
  - Удаляет параметры из URL
  
- **`payment-failed.html`** — страница ошибки
  - Проверяет статус платежа через API
  - Показывает детали и кнопки действий

## Тестирование

### В MOCK режиме (локально):

1. **Запустите сервер:**
   ```bash
   cd backend
   node server.js
   ```

2. **Заполните форму записи** на главной странице

3. **Нажмите "Оплатить через ЮКассу"**

4. **Результат (MOCK):**
   - Платёж сразу считается успешным
   - Редирект на главную с модальным окном успеха

### Для проверки ошибки:

Откройте вручную: `http://localhost:1488/payment-failed.html?payment_id=test123`

### В реальном режиме (ЮKassa):

1. Установите `MOCK_MODE=false` в `.env`
2. Заполните реальные ключи ЮKassa
3. При оплате:
   - ✅ Успешная оплата → главная + модальное окно
   - ❌ Отмена/ошибка → страница ошибки
