# 🤖 Telegram Бот для психолога

Бот для управления записями и просмотра платежей.

## 📋 Возможности

- **📅 Просмотр сеансов** - ближайшие и прошедшие
- **✅ Управление сеансами** - отметить как проведённый или отменить
- **💰 Просмотр платежей** - все платежи с статусами
- **📊 Статистика** - общая статистика по сеансам и доходам
- **🔔 Напоминания** - автоматические напоминания за 48 часов до сеанса

## ⚙️ Настройка

### 1. Получить токен бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Введите имя и username бота
4. Скопируйте полученный токен

### 2. Узнать свой Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. Скопируйте свой ID (число)

### 3. Настроить .env файл

```bash
# Скопируйте .env.example в .env
cp .env.example .env

# Отредактируйте .env
TELEGRAM_BOT_TOKEN=1234567890:XXXXXXXXXX...
TELEGRAM_ADMIN_ID=123456789
BACKEND_URL=http://localhost:1488
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Запустить бота

```bash
python bot.py
```

## 📱 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота |
| `/help` | Справка по командам |
| `/sessions` | Ближайшие сеансы |
| `/payments` | Последние платежи |
| `/stats` | Статистика |
| `/refresh` | Обновить данные |

## 🔔 Напоминания

Бот автоматически отправляет напоминания о сеансах за **48 часов** до назначенного времени.

Напоминания отправляются:
- Каждые час проверяется база данных
- Если сеанс через 47-49 часов - отправляется уведомление
- После отправки напоминание помечается как отправленное

## 📊 Структура базы данных

### Таблица `sessions`

| Поле | Описание |
|------|----------|
| id | ID сеанса |
| payment_id | ID связанного платежа |
| client_name | Имя клиента |
| client_phone | Телефон |
| client_email | Email |
| service_name | Услуга |
| session_date | Дата сеанса |
| session_time | Время сеанса |
| session_datetime | Полная дата и время |
| amount | Сумма оплаты |
| status | Статус (scheduled/completed/cancelled) |
| comment | Комментарий клиента |
| reminder_sent | Отправлено ли напоминание (0/1) |

### Таблица `payments`

| Поле | Описание |
|------|----------|
| id | ID платежа |
| order_id | ID заказа |
| amount | Сумма |
| status | Статус платежа |
| customer_name | Имя клиента |
| customer_phone | Телефон |
| customer_email | Email |
| created_at | Дата создания |
| paid_at | Дата оплаты |

## 🛠 Troubleshooting

### Бот не запускается

1. Проверьте, что токен правильный
2. Убедитесь, что база данных существует: `backend/data/payments.db`
3. Проверьте, что ADMIN_ID числовое значение

### Напоминания не приходят

1. Проверьте, что в базе есть сеансы на будущее
2. Убедитесь, что бот запущен постоянно
3. Проверьте логи на ошибки

### "Access denied"

Убедитесь, что TELEGRAM_ADMIN_ID совпадает с вашим Telegram ID.
