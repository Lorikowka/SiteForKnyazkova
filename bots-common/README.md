# bots-common

Общее ядро Python-ботов (Telegram и VK). Содержит всё, что не зависит от
конкретного мессенджера:

| Модуль | Назначение |
|--------|-----------|
| `backend.py` | HTTP-клиент backend API (единственная точка доступа к данным) |
| `formatting.py` | форматирование записей/платежей, экспорт `.ics` |
| `parsers.py` | разбор команд `/add`, `/block`, `/unblock` |
| `events.py` | отслеживание новых записей и платежей |
| `loops.py` | напоминания и утренние сводки |
| `settings.py` | чтение настроек из окружения |
| `env.py` | загрузка `.env`-файлов |
| `logging_setup.py` | логирование с ротацией |

Боты подключают пакет одним из способов:

- локальный запуск — `bot.py` добавляет соседнюю папку `bots-common` в `sys.path`;
- Docker — `ENV PYTHONPATH=/opt/bots-common`.

Зависимость — только `aiohttp`.
